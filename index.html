How we train

Every learner follows the same path, so employers can see exactly what a graduate has done.

  1. Assess. We check each learner's starting skill and English level.
  2. Train. Practical sessions with experienced trainers, in small groups.
  3. Test. Mock exams and skill assessments with written feedback.
  4. Document. A CV and portfolio that record what the learner can do.
